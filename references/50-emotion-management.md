# 50 情緒管理

> 一句話：在被否決、被夾、被追著跑的時候，先讓自己回到可以做判斷的狀態，再處理事情。

## 何時用

先說清楚：這篇談的是工作情境中的自我調節，不是心理診斷或治療。如果壓力持續、影響到睡眠、健康或生活，請尋求專業協助，或使用公司提供的 EAP（員工協助方案）資源。

- 提案或設計被當眾否決，當下很想反駁。
- 夾在業務和 RD、主管和團隊之間，兩邊都對你不滿。
- 同時被好幾個人追進度，覺得一直在救火。
- 出了問題，你是那個要負責、要去道歉的人。

何時不需要：一般的工作不順，睡一覺就過了。這篇是給「情緒已經影響到判斷或溝通」的時候。

## 動手前先問

1. **現在是什麼情緒？強度大概幾分（0–10）？** 若說不出來：先假設是「煩躁、6 分」，光是試著命名就有幫助。
2. **觸發點是什麼？是那件事本身，還是它碰到了你在意的什麼？** 例如被否決本身，還是覺得自己的專業不被尊重。若沒答：先記下發生的事，晚點再想。
3. **現在一定要回應嗎？最晚什麼時候要回？** 若沒答：預設大多數事情可以等 30 分鐘到半天。
4. **這是一次性的，還是已經持續好幾週？** 若是持續的，直接看做法第 6 步。

## 做法

1. **認出你的典型觸發點。** PM 常見的壓力源：

   | 壓力源 | 常見反應 | 可以先問自己 |
   |---|---|---|
   | 被否決 | 想當場辯護、覺得被否定的是自己 | 被否決的是方案，還是我？ |
   | 夾心 | 想討好兩邊、或乾脆放棄 | 這個衝突是我要解決的，還是我要讓它被看見？ |
   | 被追著跑 | 什麼都回、什麼都沒做完 | 哪三件事今天不做會出事？ |
   | 擔責 | 自責、或急著解釋不是我的錯 | 現在最需要的是解決，還是釐清責任？ |

   判斷標準：連續幾次記錄後，你能說出自己最容易被哪一種觸發。
2. **先處理情緒，再處理事情。**
   - 停：情緒 7 分以上時，不回訊息、不做決定。說一句「我想一下，____ 點前回你」。
   - 離開：起身走動、喝水、換個空間，幾分鐘就好。
   - 命名：寫下或心裡說出「我現在是 ____，因為 ____」。
   - 回到事情：問「我要的結果是什麼？下一步最小的動作是什麼？」
   判斷標準：情緒降到你可以同時想到對方的立場，再回應。
3. **寫了不寄的信。** 把想說的話全部寫下來，不修飾。存在草稿，不填收件人。隔一段時間再看，從裡面挑出真正需要對方知道的事實與請求，重寫一封。判斷標準：寄出的版本裡沒有形容詞攻擊、沒有「你總是」「你從來不」。
4. **一對一前的準備。** 如果需要跟讓你有情緒的人談：
   - 寫下：發生了什麼（只寫事實）、對工作的影響、我希望以後怎麼做。
   - 預想對方可能的立場，先找出你同意的部分。
   - 決定這次談話要達成的一件事，不要想一次解決所有問題。
5. **把被追著跑變成可管理的。** 列出所有被追的事，標出今天不做會出事的三件，其他回覆一個預計時間。判斷標準：每個追你的人都知道你什麼時候會給答案，而不是等你。
6. **注意持續壓力的訊號。** 如果以下狀況持續兩週以上，這已經不是靠自我調節能處理的：
   - 睡不好、常在半夜想工作的事。
   - 對原本在意的事變得麻木，或常常很想哭、很想發脾氣。
   - 身體不適（頭痛、胃痛）變多。
   - 開始逃避某些人或某些會議。
   這時請跟主管或 HR 談工作量與資源，並考慮找專業協助或使用公司 EAP 資源。求助是處理問題的方式，不是能力不足。

## 產出模板

```markdown
### 情緒當下紀錄（給自己看）
- 時間：____
- 發生什麼（只寫事實）：____
- 情緒與強度：____（__/10）
- 觸發點：____
- 我想要的結果：____
- 下一步最小動作：____
- 回覆對方的時間：____

### 一對一準備卡
- 要談的事（事實）：____
- 對工作的影響：____
- 我同意對方的部分：____
- 我希望以後：____
- 這次只求達成：____
```

### 話術

- 需要時間冷靜：「這件事我想好好想一下再回你，____ 點前給你答覆。」——不是逃避，是給出明確時間，對方也不用一直等。
- 被當眾否決時：「了解你的顧慮。我想再釐清一下，主要是 ____ 的部分嗎？我會後整理一版再找你。」——把對話移到會後，避免在情緒高點辯論。
- 被多方追進度時：「我手上現在有 ____ 件同時在跑，你這件我預計 ____ 給你。如果比這個急，告訴我要先放掉哪一件。」
- 一對一開場：「我想談一下上週 ____ 的事。我先講我看到的狀況，也想聽聽你那邊的想法。」

## 品質檢查

- [ ] 情緒 7 分以上時，沒有當下做決定或寄出訊息
- [ ] 寄出的訊息裡只有事實與請求，沒有人身評價
- [ ] 一對一前有寫下這次只求達成的一件事
- [ ] 被追進度時，每個人都拿到一個預計時間
- [ ] 有留意持續壓力的訊號，超過兩週有找人談

## 常見錯誤

- **壓下情緒假裝沒事** → 情緒會在下一次會議用更差的方式冒出來 → 至少私下命名它、寫下來。
- **情緒高點時立刻回訊息** → 文字被截圖或轉傳，事後很難收回 → 先說「我晚點回你」，給自己時間。
- **把被否決當成被否定** → 會開始防衛，聽不到真正的顧慮 → 問自己「被否決的是方案還是我」，去問清楚否決的理由。
- **一個人扛所有夾心衝突** → 兩邊都不滿，你也耗盡 → 把衝突攤到有決策權的人面前，你的角色是讓取捨被看見。
- **把求助當成軟弱** → 拖到身體或關係出問題才處理 → 持續壓力超過兩週，找主管、HR 或 EAP 談。

## 情境範例

外送平台 PM 在季度規劃會上提出的店家端訂單頁改版被 BU 主管否決，同一週業務又連續三天追客製需求進度。

- 當下紀錄：被否決後情緒「挫折、7/10」；觸發點是準備了兩週，覺得努力沒被看見。
- 當場回應：「了解，我想釐清主要是投入人力的顧慮嗎？我會後再找你。」沒有當場辯護。
- 寫了不寄的信：寫完後挑出真正要問的一件事：否決的理由是時機、成本還是證據不足？
- 一對一準備：只求達成「知道什麼條件下可以再提」。主管回答是成本，PM 回頭準備精簡方案。
- 業務追進度：回覆「這件我週四給你評估結果，若比訂單頁精簡方案急，請你跟 ____ 確認先後」。
- 兩週後若仍持續失眠，跟主管談工作量，並了解公司 EAP 的使用方式。
